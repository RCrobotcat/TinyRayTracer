```c++
for (int i = 0; i < lights.size(); i++)
{
    Vec3f light_direction = (lights[i].position - point).normalize();

    // shadow check
    float light_distance = (lights[i].position - point).norm();
    Vec3f shadow_orig = light_direction * N < 0 ? point - N * 1e-3 : point + N * 1e-3;
    // checking if the point lies in the shadow of the lights[i]
    Vec3f shadow_pt, shadow_N;
    Material tmpmaterial;
    if (scene_intersect(shadow_orig, light_direction, spheres, shadow_pt, shadow_N, tmpmaterial) && (
        shadow_pt - shadow_orig).norm() < light_distance)
        continue;

    // Blin-Phong illumination model
    diffuse_light_intensity += lights[i].intensity * std::max(0.f, light_direction * N);

    Vec3f view_direction = (orig - point).normalize();
    Vec3f half_vector = (light_direction + view_direction).normalize();
    specular_light_intensity += lights[i].intensity * powf(std::max(0.f, half_vector * N),
        material.specular_exponent);
}
    
```
------

## 一、背景：为什么要检测阴影？

当光线从相机打到一个物体表面（交点 `point`）时，我们计算光照强度。
 但如果这个交点 **被其他物体挡住了光源**，那么这个点应该处在阴影中，不能直接接收到光照，只能有环境光或间接光。

所以我们要回答的问题是：

> “从交点 `point` 朝光源方向发出的光线，会不会被别的球挡住？”

这就是 **shadow ray（阴影射线）检测**。

------

## 二、阴影射线的生成逻辑

在你的代码中，这一段是关键：

```cpp
float light_distance = (lights[i].position - point).norm();
Vec3f light_direction = (lights[i].position - point).normalize();

// 为了避免“自遮挡”伪影，沿法线偏移一点点
Vec3f shadow_orig = light_direction * N < 0 ? point - N * 1e-3 : point + N * 1e-3;
```

### 分步解释：

#### (1) `light_direction`

这是从交点指向光源的单位方向向量
$$
\text{light\_direction} = \frac{L - P}{||L - P||}
$$
 表示光线传播的方向。

#### (2) `light_distance`

记录光源到当前交点的距离，用来后面判断有没有遮挡物：
$$
d_{light} = ||L - P||
$$

#### (3) `shadow_orig`

关键！这是阴影射线的“起点”。
 如果直接从 `point` 发出阴影射线，可能会与当前物体自身表面再相交（因为浮点误差），导致错误地认为“自己挡住了自己”。
 为此，我们沿表面法线 `N` 稍微偏移一点点（`1e-3`）。

逻辑：

- 如果光线方向与法线方向夹角小于 90°（即光线从表面外侧射出），就用 `point + N * 1e-3`
- 否则从表面内部偏移一点，用 `point - N * 1e-3`

防止**自交（self-intersection）伪影**。

------

## 三、检测遮挡

```cpp
Vec3f shadow_pt, shadow_N;
Material tmpmaterial;

if (scene_intersect(shadow_orig, light_direction, spheres, shadow_pt, shadow_N, tmpmaterial) &&
    (shadow_pt - shadow_orig).norm() < light_distance)
    continue;
```

解释：

1. `scene_intersect` 会检查这条从 `shadow_orig` 出发、沿 `light_direction` 的光线（指向光源方向）是否击中场景中的任何球体；
2. 如果击中了，说明这条阴影射线被某个物体挡住；
3. 我们再比较交点到 `shadow_orig` 的距离是否 **小于光源距离**：
   - 如果小于，说明在光源之前就被遮挡；
   - 如果大于或没有命中，说明光源无遮挡，能照到该点。

若真的被遮挡，就执行 `continue;`：
 👉 跳过当前光源，不计算 diffuse 和 specular（该点在该光源下是阴影）。

------

## 四、结合到光照模型中

整个 `for` 循环中：

```cpp
for (int i = 0; i < lights.size(); i++)
{
    Vec3f light_direction = (lights[i].position - point).normalize();

    // 阴影检测
    float light_distance = (lights[i].position - point).norm();
    Vec3f shadow_orig = light_direction * N < 0 ? point - N * 1e-3 : point + N * 1e-3;
    Vec3f shadow_pt, shadow_N;
    Material tmpmaterial;
    if (scene_intersect(shadow_orig, light_direction, spheres, shadow_pt, shadow_N, tmpmaterial) &&
        (shadow_pt - shadow_orig).norm() < light_distance)
        continue;

    // 没被挡 → 计算光照
    diffuse_light_intensity += lights[i].intensity * std::max(0.f, light_direction * N);
    Vec3f view_direction = (orig - point).normalize();
    Vec3f half_vector = (light_direction + view_direction).normalize();
    specular_light_intensity += lights[i].intensity * powf(std::max(0.f, half_vector * N), material.specular_exponent);
}
```

总结逻辑：

1. 对每个光源计算阴影；
2. 如果当前点被遮挡，就 `continue;` 跳过光照计算；
3. 否则才计算该光源贡献的漫反射 + 高光。

------

## 五、图形直觉：阴影是如何形成的

想象如下几何：

```
 Light
   \
    \  (light ray)
     \ 
      o (shadow_orig)
       \
        x (other sphere)
         \
          o (hit point)
```

- 如果光线从 hit point 出发方向上存在其他物体（`x`），光线无法到达光源；
- 因此该点被遮挡；
- 在渲染结果中就呈现为阴影区域。

------

## 六、避免阴影伪影的关键技巧

| 问题                    | 原因                         | 解决办法                         |
| ----------------------- | ---------------------------- | -------------------------------- |
| 自身阴影（黑边伪影）    | 浮点误差造成射线再次命中自身 | 在射线起点加微小偏移：`1e-3 * N` |
| 阴影漏光（Shadow Leak） | 阴影射线穿透遮挡物边缘       | 适当增大偏移量或提高交点精度     |
| 阴影过强                | 环境光缺失                   | 加 ambient term 或反射           |

------

## 七、整体算法流程总结

1️⃣ 摄像机发出主射线 → 与场景求交
 2️⃣ 得到交点 `point` 和法线 `N`
 3️⃣ 对每个光源：

- 计算 `light_direction`
- 发出阴影射线 (`shadow_orig`, `light_direction`)
- 若在到光源距离内命中其他物体 → 阴影 → 不计算该光源
- 否则 → 累加漫反射 + 高光

------

## 八、结果现象

在生成的 `output.png` 中：

- 物体背光面发黑 → 没有直接光照；
- 物体之间会相互遮挡形成清晰的**阴影区域**；
- 近处物体可在远处球体表面投下阴影。
